How MapMate works

1

Locate

Your text is sent to the Nominatim geocoder, which returns real coordinates and a readable place name.

2

Query

An Overpass API query fetches matching OpenStreetMap nodes, ways and relations inside your chosen radius.

3

Compare

Results are ranked by straight-line distance and linked to numbered map pins, so list and map stay in sync.

Problem statement

Users exploring unfamiliar areas may need a focused way to discover nearby places by category and search radius. MapMate provides a location-based discovery workflow that combines searchable place listings with an interactive map, helping users compare nearby options and quickly locate them.

Focused workflow

One form: location, category and radius. The full OpenStreetMap site is a general-purpose map; MapMate is a task-specific discovery tool built on its data.

Ranked, comparable list

Every place gets a number, a distance, and details such as address and opening hours when OpenStreetMap has them.

Honest about data

Missing fields are shown as missing. Errors say what failed. Nothing is invented or silently substituted.
